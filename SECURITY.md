# Security

TraceSentinel is a local analysis prototype, not a production security boundary. The current development version is 0.1.x. Input files and generated reports may contain sensitive data; only the synthetic examples in this repository are intended for public distribution.

For a security flaw in the tool, use GitHub's private vulnerability reporting option if available. Otherwise open a minimal issue requesting a private reporting channel without including exploit details or confidential data. Do not post real authentication logs, credentials or personal data in public issues.

Reports HTML-escape event content and do not load remote scripts or assets. Do not use a finding as automatic proof of compromise, or a clean report as proof that a system is safe. There are no active scanning or account-blocking actions in v0.1.
